# Telegram-бот для птичьего хозяйства: яйца, корма, поголовье, инкубация

Бот и сайт для небольшого хозяйства. Ведёт учёт того, сколько кур несутся, чем и сколько вы их кормите, на сколько хватит корма и сколько он стоит, кто выбыл, когда обрабатывать птицу от паразитов и что сейчас в инкубаторе. Бот сам напоминает о делах и замечает проблемы: падение яйценоскости, заканчивающийся корм, короткий световой день.

Данные хранятся в SQLite, схема обновляется миграциями. Деплой идёт через GitHub Actions на VPS в Docker, сайт открывается по HTTPS через Caddy.

## Возможности

**Каждый день**
- `✅ Покормил` — отметка кормления с количеством кружек «Моей смеси». Кружки раскладываются по составу в килограммы ингредиентов (по расчёту или по взвешенной кружке) и списываются со склада. В 19:00 бот напоминает, если отметки нет.
- `🥚 Собрал яйца` — запись сбора в одно нажатие: кнопки с обычным числом. В 20:00 бот напоминает, если сбор не записан.
- `📤 Продал / отдал` — продажа (с суммой), раздача, «съели», «в инкубатор». Бот считает выручку и примерный остаток яиц дома.
- `🗓 Уход` — календарь: клещи и пухоеды, глистогонное, подстилка, дезинфекция. Кнопка «Сделал» переносит следующий срок.

**Корма и склад**
- Склад: покупки (цену указывать не обязательно), фактические остатки, история операций.
- Сколько дней хватит каждого ингредиента — по фактическому темпу кормления. Напоминание «🛒 Пора докупить» приходит за 5 и за 2 дня.
- Себестоимость: кружка смеси, корм в месяц, корм на одно яйцо, выручка минус корм.
- Замесы заранее, если нужны: расчёт по складу, чеклист, запись прошлого замеса как уже скормленного, назначение смеси стадам.

**Поголовье**
- Группы с ролями (несушки, петухи, цыплята, смешанная), год вывода и возраст, стада.
- Падёж и выбраковка с причинами, историей и отменой. Бот предупреждает, если потерь стало больше.
- Цыплят с 16 недель можно перевести во взрослых и разделить на несушек и петухов.
- Возраст стада и план замены несушек.

**Яйца**
- Обычный сбор и сбор за несколько дней (период указывается вручную или считается автоматически), история с исправлением.
- Среднее за 7 и 30 дней, прогноз, яиц на несушку, временно не несущиеся куры, поправка на погоду (Open-Meteo).
- Если 3 дня яиц заметно меньше обычного, бот предупреждает и называет причины по данным хозяйства.
- Итоги недели по воскресеньям в 20:00.

**Инкубация**
- Партии для кур, гусей, перепелов, уток и мускусных уток: день, этап, календарь работ, режимы, уход после вывода.
- Завершение вывода, история, возврат партии в активные, выводимость по видам и партиям, причины потерь (неоплод, замершие, не вылупились) с подсказкой, что проверить.

**Птицевод** — советник по данным хозяйства. Разделы: план на сегодня, корма, мало яиц, свет зимой (световой день по городу и сколько досвечивать), возраст стада, инкубация сегодня, безопасный сценарий при проблемах с птицей.

**Сервис**
- Ежедневная сводка во время уведомлений. Разделы и уведомления можно выключать.
- Выгрузка всех данных в Excel, в боте и на сайте.
- Копия базы делается на сервере раз в сутки и раз в неделю приходит администратору в Telegram. `/backup` — свежая копия по запросу.
- После деплоя администратор получает список изменений и решает, рассылать ли его пользователям.

**Сайт** повторяет бота: сводка, корма и склад, смесь, поголовье и стада, яйца, инкубация, графики, птицевод, FAQ, настройки. Открывается кнопками в боте и как Telegram Mini App.

## Главное меню

```
✅ Покормил        🥚 Собрал яйца
📤 Продал / отдал  🗓 Уход
🌾 Корма   🥚 Инкубация   🥚 Яйца
🐔 Птицевод        📊 Посмотреть сводку
⚙️ Настройки       ❓ FAQ
🌐 Открыть сайт    📱 Открыть Mini App
```

- `🌾 Корма` — ✅ Покормил, ➕ Добавить корм, 🧮 Смесь, 📦 Склад, 🐔 Поголовье и стада (➖ Падёж, 📉 Потери, 🗓 Уход), 📊 Расчёты, 💰 Себестоимость.
- `🥚 Яйца` — добавить яйца, расчёты, история, не несутся, 📤 Продал / отдал, 💰 Продажи, 📅 Итоги недели, город и погода.
- `🥚 Инкубация` — партии, план на сегодня, календарь, режимы, история, статистика, после вывода.
- `🐔 Птицевод` — план на сегодня, корма и замес, когда замес, мало яиц, инкубация сегодня, 💡 Свет зимой, 🗓 Уход за птицей, 🐔 Возраст стада и замена, проблема с птицей.
- `⚙️ Настройки` — хозяйство, часовой пояс, время уведомлений, разделы и уведомления, 📥 Выгрузить всё в Excel, о боте.

Если раздел выключен, его кнопки и уведомления пропадают, данные сохраняются. Все автоматические сообщения и их время описаны в [docs/NOTIFICATIONS.md](docs/NOTIFICATIONS.md).

## Быстрый старт для разработки

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
Copy-Item .env.dev.example .env
```

В `.env` укажите токен:

```text
BOT_TOKEN=123456:botfather_token
ENVIRONMENT=dev
DATABASE_PATH=data/incubator_dev.db
```

Запуск бота и сайта:

```powershell
python main.py
python -B scripts\web_app.py
```

Smoke-start без Telegram polling:

```powershell
python -B scripts\smoke_start.py
```

## Конфигурация

Все переменные описаны в `.env.example`, `.env.dev.example` и `.env.prod.example`.

- `BOT_TOKEN` — токен Telegram-бота. В production берётся только из переменной окружения.
- `BOT_TIMEZONE` — часовой пояс по умолчанию.
- `DATABASE_PATH` — путь к SQLite.
- `LOG_FILE`, `LOG_LEVEL` — файл и уровень логирования.
- `ADMIN_IDS` — Telegram ID администраторов через запятую. Свой ID показывает команда `/my_id`. Администраторам приходят список изменений после деплоя, недельная копия базы и сообщения о сбоях.
- `ENVIRONMENT` — `dev` или `prod`.
- `BACKUP_DIR` — каталог резервных копий.
- `REMINDER_INTERVAL_SECONDS` — частота цикла напоминаний.
- `MIN_FREE_DISK_MB` — минимальный свободный объём диска для проверки.
- `WEB_ENABLED`, `WEB_HOST`, `WEB_PORT`, `WEB_PUBLIC_URL`, `WEB_ADMIN_TOKEN`, `WEB_LINK_TOKEN` — сайт, см. [docs/OPERATIONS.md](docs/OPERATIONS.md).
- `RELEASE_VERSION`, `RELEASE_NOTES`, `RELEASE_CHANNEL`, `RELEASE_DEPLOYED_AT`, `RELEASE_COMMIT` — заполняются при деплое и показываются в «О боте».
- `GITHUB_URL`, `CHANGELOG_URL`, `DOCS_URL` — ссылки для «О боте».
- `ADMIN_STARTUP_NOTICE_MODE` — служебное сообщение администратору о перезапуске: `off`, `once_per_deploy` или `always`.

Погода загружается из Open-Meteo по названию города, запасной источник — `wttr.in`. Ключ не нужен. По координатам города бот также считает световой день.

`.env*`, базу, логи и бэкапы в Git не добавляют.

## Миграции

```powershell
python -B scripts\migrate.py
```

Новая база создаётся миграциями с нуля, существующая обновляется без удаления данных. Таблицы по группам:

- инкубация: `incubation_batches`, `reminder_settings`;
- пользователи и уведомления: `users`, `notification_log`, `service_heartbeats`;
- склад и смесь: `stock_items`, `stock_transactions` (с `price_rub`), `mix_productions`, `mix_production_items`;
- кормление: `feeding_events`, `feeding_event_items`, `feeding_settings`, `feeding_assignments`;
- поголовье: `bird_groups`, `flocks`, `flock_members`, `flock_feed_assignments`, `bird_losses`;
- яйца: `egg_entries`, `egg_outflows`, `hen_laying_exclusions`, `weather_settings`, `daily_weather`;
- уход: `care_tasks`; инкубация: `batch_losses` (причины потерь);
- служебные: `analytics_events`, `critical_errors`. Старая модель кормов (`feed_stocks`, `feed_transactions`) оставлена для совместимости.

## Production

Pull request в `main` запускает тесты, в том числе обход всех кнопок бота и всех форм сайта. Слияние в `main` запускает тесты и деплой: обновление кода на VPS, копию базы, миграции, сборку Docker-образа и запуск бота, сайта и Caddy. Подробно — [docs/DEPLOYMENT.md](docs/DEPLOYMENT.md), [docs/SERVER_SETUP.md](docs/SERVER_SETUP.md), [docs/OPERATIONS.md](docs/OPERATIONS.md).

Пользователям после деплоя автоматически ничего не приходит. Администратор получает список изменений из `docs/CHANGELOG.md` с кнопками «Разослать пользователям», «Изменить текст», «Не рассылать».

## Сайт

Сайт работает отдельным процессом (`scripts/web_app.py`). В production это контейнер `incubator-feed-web` за Caddy на `https://<ip-с-дефисами>.sslip.io`. Страницы: `/`, `/feeds`, `/mix`, `/livestock`, `/eggs`, `/incubation`, `/charts`, `/advisor`, `/help`, `/about`; выгрузка — `/export.xlsx`. Доступ — по ссылке с `?auth=<WEB_LINK_TOKEN>` (такие ссылки дают кнопки в боте) или по `WEB_ADMIN_TOKEN`. Полный список адресов — в [docs/OPERATIONS.md](docs/OPERATIONS.md).
