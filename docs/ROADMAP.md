# Планы и пробелы

Рабочая карта следующих доработок по состоянию на 17.10.2026. Что уже сделано — в [CHANGELOG.md](CHANGELOG.md).

- Быстрая смена роли группы и предупреждение о смешанной группе — `🏷 Роль` в карточке группы.
- Перевод цыплят во взрослые группы — с 16 недель, с разделением на несушек и петухов.
- Экспорт статистики — выгрузка всех данных в Excel.
- Недельные агрегаты — итоги недели и страница графиков на сайте.
- Многодневный сбор яиц на сайте — с предпросмотром.
- Учёт цен — цена покупки и себестоимость корма и яйца.
- Release notes из `docs/CHANGELOG.md` и решение администратора о рассылке.
- Кормление без замеса: «✅ Покормил» с кружками, дни запаса по ингредиентам, «Пора докупить».
- Падёж и выбраковка, продажа яиц, календарь ухода, свет зимой, возраст стада, предупреждение о падении яйценоскости.
- Копия базы вне сервера (в Telegram администратору).

## 1. Проверить на реальной работе

Самое полезное сейчас — неделя обычного использования и разбор по `/admin` (ошибки и статистика использования): какие кнопки не нажимают, где бот ошибался, где расчёты расходятся с реальностью (кружка, плотности ингредиентов, нормы).

## 2. Корма

- Консолидация моделей: старые карточки корма (`feed_stocks`) скрыть из интерфейса, оставив данные.
- Плотности ингредиентов (кг в литре) задаются в коде; дать уточнить их по взвешиванию одной кружки.
- Стада и назначение смеси нужны только для замесов заранее; при кормлении кружками можно упростить раздел «Поголовье и стада».

## 3. Яйца

- Привязка временно не несущейся курицы к группе поголовья и подсказка, что срок исключения истёк.
- Заметка к сбору яиц в Telegram.
- Сравнение прогноза с фактом и подстройка погодной поправки по данным хозяйства.

## 4. Поголовье

- Взвешивание и заметки по группе (например, после болезни).
- Учёт покупки птицы (откуда, сколько стоила) для полной окупаемости.

## 5. Инкубация

- Причины потерь по партии отдельными полями (неоплод, замершие, не вылупились) вместо свободной заметки.
- Напоминание отобрать и хранить яйца на инкубацию заранее (свежесть до 7–10 дней).

## 6. Птицевод

- Свободный вопрос с классификацией темы, без медицинской диагностики.
- Учёт фактической температуры в курятнике.

## 7. Технические

- Мини-приложение Telegram: проверка подписи `initData` вместо ссылки с токеном (см. [FINAL_HARDENING_BACKLOG.md](FINAL_HARDENING_BACKLOG.md)).
- Восстановление из копии через бота (сейчас — по инструкции в [BACKUP_RESTORE.md](BACKUP_RESTORE.md)).
- Админка: текущий commit, время деплоя и количество записей по разделам.
- Тесты на production-подобной базе со старыми складскими позициями и стадами.

## Правило для документации

Каждая пользовательская функция обновляет: строку в `docs/CHANGELOG.md` (уходит администратору после деплоя), `app/content/help/*.md`, `docs/USER_COMMANDS.md` и, если есть автоматические сообщения, `docs/NOTIFICATIONS.md`.
